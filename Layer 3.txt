# NIAT PathFinder AI — Complete source code

We'll build the actual Track A: Top-of-Funnel AI Career Discovery System.

The implementation below uses:

- Next.js + TypeScript + Tailwind CSS — frontend and backend.
- OpenAI API — AI career recommendations and personalized reports.
- Supabase — lead database and analytics.
- n8n — automated lead routing and follow-up.
- Vercel — public deployment.

The application will work even without Supabase or n8n initially; those integrations can be enabled through environment variables. AI generation requires an OpenAI API key.

This is the core intelligence component.

`app/api/generate/route.ts`

typescript

```typescript

import { NextResponse } from "next/server";
import { z } from "zod";
import { openai } from "@/lib/openai";

export const runtime = "nodejs";

const schema = z.object({
  studentName: z.string().trim().min(1).max(60),
  stream: z.string().max(30),
  interests: z.array(z.string().max(60)).min(1).max(5),
  experience: z.string().max(60),
  favoriteSubject: z.string().max(60),
  careerGoal: z.string().max(100),
  language: z.enum([
    "English", "Telugu", "Hindi",
    "Tamil", "Kannada", "Malayalam"
  ])
});

export async function POST(request: Request) {
  try {
    if (!process.env.OPENAI_API_KEY) {
      return NextResponse.json(
        { error: "AI service is not configured" },
        { status: 503 }
      );
    }

    const parsed = schema.safeParse(await request.json());

    if (!parsed.success) {
      return NextResponse.json(
        { error: "Please provide valid assessment details." },
        { status: 400 }
      );
    }

    const student = parsed.data;

    const response = await openai.chat.completions.create({
      model: process.env.OPENAI_MODEL || "gpt-4o-mini",
      temperature: 0.5,
      response_format: { type: "json_object" },
      messages: [
        {
          role: "system",
          content: `
You are PathFinder AI, a responsible career discovery assistant
for Indian Class 12 students.

Generate practical career exploration guidance based on the
student's interests, academic stream and experience.

Return valid JSON with exactly these fields:
{
  "introduction": "string",
  "careerPaths": [
    {
      "title": "string",
      "description": "string",
      "skills": ["string"],
      "suitability": "string"
    }
  ],
  "recommendedSkills": ["string"],
  "beginnerProject": "string",
  "projectDescription": "string",
  "roadmap": [
    {
      "period": "Month 1",
      "goal": "string",
      "activities": ["string"]
    }
  ],
  "nextSteps": ["string"],
  "realityCheck": "string"
}

Rules:
- Return 3 relevant career paths.
- Return 5 recommended skills.
- Return 3 roadmap stages covering 90 days.
- Keep projects achievable for beginners.
- Translate the entire response into the requested language.
- Be encouraging but realistic.
- Never guarantee employment, salary, admission or placement.
- Do not claim that NIAT guarantees any particular outcome.
- Explain that recommendations are exploratory, not an aptitude test.
- Do not assume that every career is suitable for every stream.
- Mention prerequisites where relevant.
- Do not fabricate NIAT student achievements or statistics.
`
        },
        {
          role: "user",
          content: JSON.stringify({
            student: student.studentName,
            academicStream: student.stream,
            interests: student.interests,
            experience: student.experience,
            favoriteSubject: student.favoriteSubject,
            careerGoal: student.careerGoal,
            responseLanguage: student.language
          })
        }
      ]
    });

    const content =
      response.choices[0]?.message?.content;

    if (!content) {
      throw new Error("Empty AI response");
    }

    const report = JSON.parse(content);

    return NextResponse.json({
      success: true,
      report
    });

  } catch (error) {
    console.error("Career generation error:", error);

    return NextResponse.json(
      { error: "Unable to generate your report. Please try again." },
      { status: 500 }
    );
  }
}
```

alter table public.pathfinder_events enable row level security;

-- No public access policies.
-- All database operations go through protected server APIs.

## 8. Lead qualification and automation API

`app/api/leads/route.ts`

typescript

```typescript

import { NextResponse } from "next/server";
import { z } from "zod";
import { getSupabase } from "@/lib/supabase";

export const runtime = "nodejs";

const schema = z.object({
  studentName: z.string().trim().min(1).max(60),
  email: z.string().email().max(150),
  phone: z.string().max(20).optional(),
  city: z.string().trim().min(1).max(80),
  stream: z.string().max(30),
  interests: z.array(z.string()).min(1).max(5),
  experience: z.string(),
  favoriteSubject: z.string(),
  careerGoal: z.string(),
  language: z.string(),
  consent: z.literal(true),
  guardianConsent: z.boolean(),
  report: z.record(z.string(), z.unknown()).optional()
});

export async function POST(request: Request) {
  try {
    const parsed = schema.safeParse(await request.json());

    if (!parsed.success) {
      return NextResponse.json(
        { error: "Valid details and consent are required." },
        { status: 400 }
      );
    }

    const lead = parsed.data;

    const score =
      (lead.interests.length >= 2 ? 20 : 10) +
      (lead.careerGoal ? 20 : 0) +
      (lead.city ? 10 : 0) +
      (lead.phone ? 15 : 0) +
      (lead.email ? 15 : 0) +
      (lead.report ? 20 : 0);

    const category =
      score >= 80 ? "high-intent" :
      score >= 50 ? "medium-intent" :
      "early-interest";

    const supabase = getSupabase();

    const { data, error } = await supabase
      .from("pathfinder_leads")
      .insert({
        student_name: lead.studentName,
        email: lead.email,
        phone: lead.phone || null,
        city: lead.city,
        stream: lead.stream,
        interests: lead.interests,
        experience: lead.experience,
        favorite_subject: lead.favoriteSubject,
        career_goal: lead.careerGoal,
        language: lead.language,
        consent: lead.consent,
        guardian_consent: lead.guardianConsent,
        lead_score: score,
        lead_category: category,
        report: lead.report || null
      })
      .select("id, lead_score, lead_category")
      .single();

    if (error) {
      throw error;
    }

    // Send the lead to n8n after successful database insertion.
    if (process.env.N8N_WEBHOOK_URL) {
      try {
        await fetch(process.env.N8N_WEBHOOK_URL, {
          method: "POST",
          headers: {
            "Content-Type": "application/json"
          },
          body: JSON.stringify({
            event: "new_pathfinder_lead",
            lead_id: data.id,
            student_name: lead.studentName,
            email: lead.email,
            phone: lead.phone || null,
            city: lead.city,
            interests: lead.interests,
            career_goal: lead.careerGoal,
            language: lead.language,
            lead_score: score,
            lead_category: category
          }),
          signal: AbortSignal.timeout(8000)
        });
      } catch (automationError) {
        console.error("n8n notification failed:", automationError);
      }
    }

    return NextResponse.json({
      success: true,
      leadId: data.id,
      score,
      category
    });

  } catch (error) {
    console.error("Lead submission error:", error);

    return NextResponse.json(
      { error: "Unable to save your enquiry." },
      { status: 500 }
    );
  }
}
```

## 9. Analytics API

`app/api/analytics/route.ts`

typescript

```typescript

import { NextResponse } from "next/server";
import { getSupabase } from "@/lib/supabase";

export const runtime = "nodejs";

export async function POST(request: Request) {
  const key = request.headers.get("x-admin-key");

  if (
    !process.env.ADMIN_DASHBOARD_KEY ||
    key !== process.env.ADMIN_DASHBOARD_KEY
  ) {
    return NextResponse.json(
      { error: "Unauthorized" },
      { status: 401 }
    );
  }

  try {
    const supabase = getSupabase();

    const { data, error } = await supabase
      .from("pathfinder_leads")
      .select("*")
      .order("created_at", { ascending: false })
      .limit(500);

    if (error) throw error;

    const leads = data || [];

    const total = leads.length;
    const highIntent = leads.filter(
      x => x.lead_category === "high-intent"
    ).length;

    const cities: Record<string, number> = {};
    const concerns: Record<string, number> = {};

    leads.forEach(lead => {
      cities[lead.city] = (cities[lead.city] || 0) + 1;

      lead.interests?.forEach((interest: string) => {
        concerns[interest] = (concerns[interest] || 0) + 1;
      });
    });

    return NextResponse.json({
      success: true,
      metrics: {
        total,
        highIntent,
        mediumIntent: leads.filter(
          x => x.lead_category === "medium-intent"
        ).length,
        earlyInterest: leads.filter(
          x => x.lead_category === "early-interest"
        ).length,
        highIntentRate: total
          ? Math.round(highIntent / total * 100)
          : 0,
        cities,
        interests: concerns
      },
      leads
    });

  } catch (error) {
    console.error(error);

    return NextResponse.json(
      { error: "Unable to retrieve analytics." },
      { status: 500 }
    );
  }
}
```

## PathFinder lead automation

Webhook Trigger

Receives qualified lead from Next.js

Lead Classification

Categorizes interest, city and language

Google Sheets / CRM

Creates an admissions follow-up record

WhatsApp / Email Follow-up

Sends a message only where appropriate consent and channel permissions exist

Use a Webhook node configured for POST, followed by an IF node and a CRM/Google Sheets node.
